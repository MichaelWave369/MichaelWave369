## One Field. Many working experiments.

I came to software through real-world network infrastructure, where a design only matters if the cables, computers, people, and constraints agree. I now build original tools across operating systems, local inference, networked collaboration, experimental research, creative software, and playable universes.

The projects are independent repositories with shared design values, **not a claim that every component is already integrated or production-ready**. Some are working browser applications, some are local experiments, and others are research proposals. A green build is not a safety certification; an interesting simulation is not a scientific discovery.

## Research with receipts

Experiments are labeled as **observed**, **inferred**, **simulated**, or **proposed**. Negative results, limitations, and test conditions belong beside successful runs. Public research records are archived in the [Φ369 Zenodo community](https://zenodo.org/communities/enter-the-field-phi369/records). The repository index excludes private work and an index listing never grants an agent permission to operate a project.

## How I build

**Question → smallest useful implementation → measurements and counterexamples → evidence receipt → review → human decision → revise.**

Local-first where practical. Open formats over lock-in. Human consent over agent convenience. Original tools, affordable access, and a good reason to laugh while debugging.
